Read, inspect and write XLSX files

xlvane is an MIT-licensed library for Excel workbooks that treats every input file as untrusted. ESM only, with one runtime dependency (fflate). The core works with Uint8Array and has no Node.js dependencies; file helpers are in xlvane/node.

npm install xlvane

What it does

Reading

Values, dates, formulas with their cached results, styles, merged cells, hyperlinks, notes, tables, pictures, charts, data validation and conditional formatting.

inspect()

Plain JSON about a workbook: sheets, used ranges, the detected header row, column types with examples, formulas, defined names and warnings.

Writing

Styles, column widths, frozen panes, filters, rich text, links, notes, images, charts (column, bar, line, pie, scatter and area), tables, sheet rules and print settings. The output is deterministic, except the random salt of a protection password.

Tasks in one call

readTable with schema validation, writeTable, CSV and JSON in both directions, editCells, appendRows, insertRows, deleteRows and diff.

Streaming

Read row by row and write rows pulled from an iterable, with Web Streams, so the worksheet cells are never all in memory.

Untrusted input

ZIP and XML limits, no DTDs or external entities, file data never used as object keys, CSV formula-injection protection. Every error has an XLV_E_* code, a location and a hint.

Command line

xlvane inspect, read, convert, create, edit, diff, validate, migrate and mcp, with --json output that follows documented schemas.

MCP server

@xlvane/mcp: tools for MCP clients to inspect, read, compare and validate workbooks, and with --allow-write to write, edit and convert them, only inside the directories given at start.

@xlvane/compat

The commonly used part of the exceljs 4.4.0 API on top of xlvane, installed under the name exceljs; the differences are listed in the compatibility guide. An independent project, not affiliated with exceljs.
