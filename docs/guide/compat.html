@xlvane/compat is now @xlvane/exceljs

From version 1.3.3 the exceljs-compatible package is published as @xlvane/exceljs. @xlvane/compat gets no new versions and is marked as deprecated on npm.

To switch, change the alias in package.json from "exceljs": "npm:@xlvane/compat@^1" to "exceljs": "npm:@xlvane/exceljs@^1", or run npx xlvane migrate --force. The code keeps importing exceljs.
